# Rollout headroom (AT-10) counting rules

AT-10 sums the rollout peak of every workload and compares it with the ResourceQuota `hard` values for `requests.cpu`, `requests.memory`, `limits.cpu`, `limits.memory`, and `pods`. Counted: Deployments and StatefulSets. Not counted in v0.1: Argo Rollouts (deferred to v0.2 in the CEO review of 2026-10-10: the kind e2e installs no Argo, and the canary rule needs a traffic-routing case), DaemonSets (their count follows machines, not the tenant), Jobs and CronJobs (their overlap follows the schedule), and bare Pods; the reason names what was and was not counted and shows the quota's `used` values so the reader sees what else consumes it. Peak per workload: Deployment = replicas + maxSurge (absolute or percent rounded up, default 25%); StatefulSet = replicas. For v0.2: Rollout blue/green = replicas + (previewReplicaCount, else replicas); Rollout canary without traffic routing = replicas + maxSurge; Rollout canary with `trafficRouting` set and `dynamicStableScale` unset = 2 × replicas, because the stable set stays at full size while the canary scales up. Pod size follows the Kubernetes rule: max(sum of regular containers, largest init container); a container with no request uses the LimitRange `defaultRequest` if one exists, else zero with a note. All workloads are assumed to roll out at once (worst case, stated in the reason). No safety multiplier and no overhead constant: only public Kubernetes and Argo semantics, so a reader can reproduce the number by hand.

Estimate, not bound (outside review, 2026-10-11): pods that are terminating still count against the quota until they are gone, so the true momentary peak can exceed the model. Every AT-10 reason therefore starts with "estimate", and its note names what is not counted (D86, D106). A verdict built on inputs the identity could not read is not a PASS: unreadable HPAs, or an unreadable LimitRange while a counted container has no explicit sizes, make AT-10 SKIP with the missing permission, unless the partial sum already exceeds the quota, which is FAIL.
